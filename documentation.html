1. System Architecture

TinyCAD is a browser-based application leveraging the HTML5 Canvas API for direct-to-buffer rendering. It uses a global array to manage geometry and browser localStorage for state persistence.

The Object Model

Entities are stored in the lines[] array. A standard entity schema includes:

{
    x1, y1, x2, y2: number, // World coordinates
    type: "line" | "window" | "door",
    locked: boolean,        // Length constraint
    mirrored: boolean       // Door swing orientation
}

2. Coordinate Systems

The application maintains a strict separation between Screen Space (pixels) and World Space (CAD plane).

$World_{pos} = \frac{Screen_{pos}}{Zoom} + Camera_{offset}$

This allows for infinite panning (Middle-Click) and zooming (Scroll Wheel) without losing precision.

3. Drawing & Snap Logic

Vertex Snapping

To ensure structural integrity, the engine performs a proximity check (SNAP_DIST = 15) on every mouse event. The engine calculates the Euclidean distance to determine if the cursor should "snap" to a vertex:

$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$

4. Architectural Features

Window Rendering

Windows are rendered as double lines offset from the central vector. This creates a standard architectural representation within the vector space.

Door Flip/Mirror

The mirrored property in the object model inverts the door's arc swing and leaf rotation. This allows users to toggle the opening direction of any door entity via the property inspector.

5. Angular Parametric Drafting Enhanced

The Angular Parametric tool (found in the Addons menu) generates geometry from text-based commands using the format: Angle-Distance-Type.

New Feature: Angle Reference Modes
Users can now toggle between two coordinate reference modes for geometric generation:
  • Relative Mode (Default): Each input angle is an offset added to the heading of the previous line segment.
  • Absolute Mode: Each input angle refers to the global coordinate system (0° is East/Horizontal).

6. Export Engine

TinyCAD calculates the Axis-Aligned Bounding Box (AABB) of the drawing to ensure exported files contain all geometry without excess whitespace.

  • SVG/PNG: Visual formats for documentation.
  • DXF: Industry-standard vector format. Note that the Y-axis is inverted to match standard Cartesian CAD systems.
  • JSON: Full project state for backup and re-import.
